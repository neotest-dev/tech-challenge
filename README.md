# Tech Challenge 2026

Sitio web del concurso Tech Challenge, desarrollado con React, TypeScript y Vite.

## Requisitos

- Git
- Node.js 20.19+ (o 22.12+) y npm

## Clonar e iniciar

Reemplaza `<URL_DEL_REPOSITORIO>` por la dirección Git del proyecto:

```bash
git clone <URL_DEL_REPOSITORIO>
cd tech-challenge
npm ci
npm run dev
```

Abre en el navegador la dirección local que muestra Vite (normalmente `http://localhost:5173`).

## Comandos útiles

```bash
npm run build    # Compilar para producción
npm run preview  # Probar localmente la compilación
npm run lint     # Revisar el código con ESLint
```
